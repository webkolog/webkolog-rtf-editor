**Webkolog RTF Editor** is a comprehensive and user-friendly text editor designed for anyone working with Rich Text Format (RTF) files. Built with C#, it not only allows you to open and edit texts but also offers rich features like text formatting, image insertion, and precise alignment. With multi-language support, a tabbed workspace, and built-in data loss prevention features, it ensures both an efficient and secure editing experience for managing everything from professional documents to personal notes.

## Features

* 🚀 **Easy File Opening:** Quickly open RTF files by dragging and dropping them directly onto the program window, preventing duplicate instances and keeping your workspace organized.
* 🗂️ **Tabbed Working Environment:** Work on multiple RTF files simultaneously with multi-tab support, allowing for seamless switching between documents.
* 🛠️ **Advanced Tab Management:** Conveniently manage your workspace with features like closing tabs to the right or left, closing all tabs at once, or closing everything except the selected active tab.
* 🔒 **Data Loss Prevention:** Automatically detects unsaved changes and warns you before closing, with visual indicators in the tab header to highlight modified files.
* 📝 **Rich Text Formatting:** Format your text with bold, italic, underline, and strikethrough options, alongside full text alignment controls (left, right, center).
* 🖼️ **Image Insertion:** Easily enrich your documents by embedding images directly into your RTF files.
* 🔍 **Quick Search & Replace:** Swiftly find and replace words or phrases throughout your active text.
* 🕒 **Practical Utilities:** Built-in tools to quickly insert the current date/time, copy the file path/name with one click, or instantly open the file's directory.
* 👁️ **Read-Only Mode:** Protect critical documents from accidental modifications by switching to a safe viewing-only mode.
* 📊 **Real-Time Position Tracking:** View your current line and column numbers instantly via the status bar for precise editing layout.

## Installation & Requirements

1. Clone or download this repository:
```bash
   git clone https://github.com/webkolog/webkolog-rtf-editor.git
```

2. Ensure you have **.NET Framework 4.5** or higher installed on your Windows machine.
3. Configure your **MS SQL Server 2008** environment connection details if you plan on modifying or running the source solution.
4. Run the compiled executable file (`.exe`) to start the editor.

## Usage Overview

Using Webkolog RTF Editor is incredibly simple:

1. **Opening Files:** Drag and drop any `.rtf` file onto the main window, or use the traditional **File > Open** menu.
2. **Formatting & Media:** Use the intuitive toolbar at the top of the editor to apply structural styles (bold, italic, alignment) or insert images into your document.
3. **Tracking & Searching:** Utilize the dedicated quick search tools to locate text patterns, while keeping an eye on the bottom status bar for line/column readouts.
4. **Saving:** Click the **Save** button to commit changes. If you attempt to exit with modified work, the program will automatically prompt a safety warning.
